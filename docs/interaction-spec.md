## § selectFiles — 文件选择器

**使用场景**: `init` 冲突文件选择、`sync -i` 交互补缺、`sync --patch` 冲突勾选

**键盘命令**:

| 键 | 行为 | 说明 |
|----|------|------|
| `a` | 全部跳过 | 清空所有勾选（deselect all），回车后不写入任何文件 |
| `A` | 全部覆盖 | 选中所有文件（select all），回车后全部覆盖写入 |
| `1`-`N` | 切换 | toggle 对应编号的文件（勾选↔取消） |
| `↑` `↓` | 滚动 | 文件列表超过可见区域时上下滚动 |
| `Enter` | 确认 | 以当前勾选状态执行写入 |
| `q` / `quit` | 退出 | 取消操作，不写入任何文件 |

**显示信息**:

- `[✓]` — 已勾选（将被写入）
- `[ ]` — 未勾选（将被跳过）
- `+N 行 (新建)` — 新文件，共 N 行
- `~N 行 (覆盖)` — 已有文件，N 行有变动（simple line-by-line diff）

**初始状态**: 所有文件默认勾选（`[✓]`），即默认行为是"全部覆盖"。用户可通过 `a` 改为全部跳过。

**调用方**: `src/caijuehub/strategies/writer.strategy.ts`（init 流程）、`src/cli/commands/sync.ts`（sync 命令）

**约束**:
- 不改变默认行为——首次进入全选
- `a`/`A` 区分大小写
- `q` 不区分大小写
- 无外部依赖，纯 Node.js readline + ANSI

## § init 交互流程

**模式**: 非交互（`--yes` / `--force`）、交互（默认）

| 模式 | 冲突文件处理 |
|------|-------------|
| `--force` | 全部覆盖，不询问 |
| `--yes` | 全部跳过，只写新文件 |
| 默认 | 调用 `selectFiles` 让用户选择 |

---

## § 编写新交互界面的规则

1. **键盘语义统一**: `a` = 跳过/清空，`A` = 覆盖/全选，`q` = 退出
2. **初始状态**: 默认最安全的选择（通常是全选→用户主动减）
3. **引用本文档**: 代码注释里写 `详见 docs/interaction-spec.md § xxx`
4. **零依赖**: 只用 Node.js 内置模块
